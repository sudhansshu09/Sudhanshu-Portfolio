# Sudhanshu Kumar Portfolio

## 1. Normal HTML version
Open `index.html` directly in the browser.
Keep these files/folders beside it:
- `image/pngmy.png`
- `image/Sudhanshu Kumar.pdf`

The CSS and JavaScript are already inside `index.html`.

Before using the contact form, replace the three EmailJS placeholders in the HTML.

## 2. React + Vite version
Recommended structure:
src/
  App.jsx
  App.css
  main.jsx
public/
  image/
    pngmy.png
    Sudhanshu Kumar.pdf

Install:
npm install

Create `.env` from `.env.example` and add your EmailJS keys.

Run:
npm run dev
